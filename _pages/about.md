## Hi, I’m Xiangxin (Sean) Zhao 👋

I am a PhD Candidate in Computer Science at University College London,  
supervised by **Dr. He Ye** and **Prof. Federica Sarro**.

My research is on the **reliability of LLM coding agents**. I study how and why coding agents fail, and whether a failed agent execution can be repaired rather than restarted — extending Automated Program Repair from programs to agent trajectories. I also work on evaluating whether AI-generated code reviews can be trusted.

**Research interests:** LLM coding agents · agent failure analysis · automated agent repair · automated program repair · code review
